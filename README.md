# dsh-path-guard

在 DSH 开启 **完全权限（`danger-full-access`）** 时，仍然阻止 AI 读取/写入指定路径的 Harness 插件。

- 两种访问控制档位：**完全不可见**（连目录结构、文件名都看不到）与**半访问控制**（可见文件名/结构但不可读内容，或可读不可写）。
- 支持**豁免规则**：更具体的路径规则覆盖更宽泛的规则，例如 `.ssh/**` 设为半访问，但 `.ssh/README.md` 豁免为可读。
- 通过 DSH 0.1.7-rc2 的**前端插件配置页**（Settings → 内置插件 → 本插件）配置，无需手改 YAML。

设计与实施计划见 [`docs/PLAN.md`](docs/PLAN.md)。
